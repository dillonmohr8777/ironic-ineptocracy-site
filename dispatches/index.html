02

Who Gets Spent

The machine

The machine does not ask who is guilty. It asks who can be processed.

Purpose
Introduce the Draft Machine without overexplaining plot.
Visual
A government form sliding out of a printer under fluorescent light. The key fields are blacked out. One red stamp reads SELECTED.

Read who gets spent

03

The Memory Economy

The edited memory

Power does not only want the event. It wants the version of the event people are allowed to keep.

Purpose
Introduce the memory-control theme as the intellectual hook.
Visual
A timeline pinned under glass. Certain years have been erased so cleanly the page looks designed that way.

Read the memory economy

04

The Garnier Position

The man above the hill

Garnier does not need the throne. He owns the room around it.

Purpose
Make Dijon Garnier the month-one villain asset.
Visual
A mansion at night above the city. The windows glow like servers. The driveway looks too empty.
