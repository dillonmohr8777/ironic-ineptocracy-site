Character index

Every character gets a file, not a biography.

Nine names are public. Each one opens a file: what the machine sees, what it wants, and what it can't afford to have known. The rest of the roster stays sealed until the book.

Subject · live · Black intellect · file BI 01

Darnell Covington

Seventeen, mathematically adroit, Harvard bound, and suddenly legible to people who confuse promise with property.

Subject · drafted · QB · Rosedale, Mississippi

Javon Whitfield

Six foot five, 242 pounds, state title gravity, and a mind nobody gets to reduce to muscle.

POTUS · erratic · President · back in office

Ronald McNulty

Reality television ego with executive power and a talent for making collapse sound procedural.

Subject · evading · Tecca · GAN PAC · class war architect

Dijon Garnier

Private capital with a cigar, a mansion, a technological alibi, and a brutal appetite for controllable memory.

Subject · unsealed · File D 09 · Langley route

Alec Daheim

A disciplined weapon with green eyes, an empty column, and a conscience arriving later than it should.

Supporting file · Mamilla file · brunette dossier

Avigail

Supporting file · CIA field file · blonde dossier

Sabrina

Blue eyes returned from gray, a Midwestern accent under fire, and a gun hand that knows obedience can be manufactured.
